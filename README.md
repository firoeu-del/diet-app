# 🥗 رژیم‌نویسی بر اساس وزن ایده‌آل (IBW / AIBW)

وب‌اپ فارسی و کاملاً آفلاین برای محاسبه وزن ایده‌آل، کالری روزانه، درشت‌مغذی‌ها و برنامه وعده‌های غذایی — قابل نصب روی گوشی (PWA).

## 🚀 راه‌اندازی با GitHub Pages

1. در همین ریپازیتوری به **Settings → Pages** بروید
2. در بخش «Build and deployment»، گزینه **Source** را روی **Deploy from a branch** بگذارید
3. Branch را **main** و پوشه را **/(root)** انتخاب کنید و **Save** بزنید
4. بعد از حدود یک دقیقه اپ در این آدرس در دسترس است:

```
https://firoeu-del.github.io/diet-app/
```

## 📱 نصب روی گوشی

آدرس بالا را در کروم اندروید باز کنید → منوی ⋮ → **افزودن به صفحه اصلی (Add to Home screen)**

## 📦 ساخت APK (اختیاری)

آدرس اپ را در [PWABuilder](https://www.pwabuilder.com) وارد کنید و بسته اندروید (APK/AAB) بگیرید.

## ✨ امکانات

- محاسبه وزن ایده‌آل (IBW) و وزن تعدیل‌شده (AIBW) و کالری هدف
- درشت‌مغذی‌های روزانه با درصدهای قابل‌تنظیم
- تاریخچه محاسبات (ذخیره در حافظه مرورگر)
- برنامه وعده‌ها و واحدهای غذایی
- حالت تاریک/روشن، طراحی شیشه‌ای، کاملاً آفلاین
